method contract

输入、设备写入、返回、下一位消费者

RECEIVES

batch: ScheduleBatch、draft_input: DFlashDraftInputV2、prefix_lens，以及刚由 alloc_verify_window() 得到的 VerifyWindow。

MUTATES

Draft ModelRunner.forward() 使用 verify cache locations 写设备侧 Draft KV，并产出 raw_hidden；它不把 proposal 直接提交到 Scheduler。

RETURNS

DraftProposal：MASK-shaped draft_block_ids、真实 draft_block.draft_tokens、draft hidden、可选 confidence/tap 与 folded 标志。

NEXT CONSUMER

DSparkWorkerV2._forward_decode() 取出 tokens；04 的 DSparkVerifyPlanner 计算/接收 confidence，解析 budget，再生成 layout。

serial dependency

Markov head 只串行小头，不串行 Draft transformer

每一步将上一步真实采样 token 作为 prev_tokens；这正是后置 token 拥有前置 token 条件的来源。

STEP 0 · slot h0Q0 = apply(L0, prev=X, h0)a
STEP 1 · slot h1Q1 = apply(L1, prev=a, h1)b
STEP 2 · slot h2Q2 = apply(L2, prev=b, h2)c
STEP 3 · slot h3Q3 = apply(L3, prev=c, h3)d
CUDA / concrete dynamic class：实例始终是 self._proposer.draft_model.markov_head；其实际类由 checkpoint 配置选择 sglang.srt.models.dspark.VanillaMarkov、GatedMarkovHead 或 RNNHead。它们共享 sample_block() 契约。

route boundaries · all visible

三条路线在 Draft 阶段哪里相同、哪里分开

STATIC · GREEDY

每个 Markov step 的 token 都取 argmax(step_logits)；若 Draft CUDA Graph 已捕获 sampler，proposal 本身仍可能 folded，但 STATIC 会在 04 得到 layout=None，因此不会命中 folded accept 快路。

COMPACT · SAMPLING

按每请求 temperature 与 greedy mask 采样；保存实际 corrected_logits 和 temperatures，06 才能重建真实 proposal 分布 P_D。

FOLDED · GREEDY

仅当 draft_sampler != None、fwd.can_run_graph、all-greedy 时，采样尾部来自 graph buffer；corrected_logits=None，proposal.confidence 也可能已填。完整条件见 08。

OFF：这里不计算普通路径 confidence，也不解析 budget。proposal.confidence is Optional 是返回契约；具体“缺失时如何算”从 04 开始。

why here / omitted failure

这组顺序不能交换

WHY HERE

先用 MASK 并行生成每个槽位的 draft hidden/base logits，再用小型 Markov head 补真实前缀依赖：将昂贵 transformer 从 G 次降为一次，同时保留链式 proposal。

FAIL · SKIP MARKOV

若直接从四个 base logits 独立采样，b/c/d 没有看到 a/b/c；proposal 语义改变，后续 acceptance 对应的 Draft 分布也不再是实现中的 P_D。

FAIL · DROP Q

sampling 路径若不保留 corrected_logits/temperatures，06 无法重建实际 proposal 概率并做拒绝采样残差修正；这会改变 Target 输出分布。

draft_block_ids = full((bs, gamma), MASK)
draft_block_ids[:, 0].copy_(draft_input.bonus_tokens)
draft_forward_batch = ForwardBatch(
    forward_mode=ForwardMode.TARGET_VERIFY,
    batch_size=bs,
    input_ids=draft_block_ids.flatten(),
    positions=positions_2d[:, :gamma].reshape(-1),
    out_cache_loc=verify_cache_loc_2d[:, :gamma].reshape(-1),
    spec_algorithm=SpeculativeAlgorithm.DSPARK,
)
draft_out = self.draft_model_runner.forward(draft_forward_batch)
fwd = DraftForwardResult(
    draft_block_ids=draft_block_ids,
    raw_hidden=draft_out.logits_output.hidden_states,
    draft_hidden_3d=raw_hidden.view(bs, gamma, -1),
    can_run_graph=draft_out.can_run_graph,
)

# normal proposal tail
base_logits, confidence_tap = self.draft_model.compute_base_logits(fwd.raw_hidden)
draft_block = sample_draft_block(
    base_logits=base_logits.view(bs, gamma, -1),
    anchor_tokens=draft_block_ids[:, 0],
    draft_hidden=fwd.draft_hidden_3d,
    markov_head=self.draft_model.markov_head,
    sampling_info=sampling_info,
)
return DraftProposal(..., confidence=None,
                     confidence_tap=confidence_tap, folded=False)
