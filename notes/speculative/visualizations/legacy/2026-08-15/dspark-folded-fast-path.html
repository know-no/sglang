不是另一套算法。

capture vs replay

Python 调用与 CUDA graph 内 device work 不要混为一层

1

WARMUP / CAPTURE · once

Target runner 调用 epilogue tail hook；_ensure_out() 分配静态输出 buffers，然后 scatter / greedy accept / finalize / optional commit 被录入 graph。正在 capture 时禁止临时分配新输出。

2

CPU PRE-REPLAY · every step

begin_step() 将本轮 verify_lens 写入 verify_lens_buf，并把 inject_gate_buf 设为 1 或 0；decode graph runner 同时把 ForwardBatch 数据装入 static buffers。

3

CUDA REPLAY · asynchronous enqueue

Target graph 计算 logits/hidden；tail epilogue 在同一 replay 尾部 scatter 到 strided buffers、执行 greedy accept/finalize，并由 gate 决定 commit 长度是否为零。

4

PYTHON READ / REJOIN

run_compact() 取得 epilogue tensor views；read_accept(bs) 返回切片。Python 不重复 kernel，但后续对 tensor 的使用仍遵循 PyTorch/CUDA stream 依赖。

时序重点：capture_hook() 的 Python body 发生在图捕获阶段；以后 replay 执行的是被捕获的 device 操作，不是重新解释这段 Python。begin_step() 必须位于 Target launch 之前，否则 graph 会读取上一轮 verify_lens / inject gate。

fallback and rejoin

快路径失败不是错误：它必须无缝回到普通实现

CUDA · FAST

folded_accept = true

  1. 读取 graph 内 strided tensors。
  2. accept_and_finalize() → read_accept(bs)。
  3. 若 epilogue.folds_commit，跳过 graph 外 commit_hidden()。
  4. 进入 common tail。
FAIL → FALLBACK

任一 guard = false

  1. proposal.folded=false：Draft proposal 留在 eager sampler。
  2. run_compact=false：Target 走 non-compact。
  3. can_run_cuda_graph=false：run_compact 自己做 scatter。
  4. folded_accept=false：06 normal accept/finalize 重算；若 graph 内 optional commit 被捕获，inject_gate=0 使它不写有效 commit。
REJOIN · same observable result：两路都得到 accept: AcceptOuts、清空 logits_output.hidden_states，然后执行 observability、make_next_draft_input(bonus, new_seq_lens) 与 GenerationBatchResult。Folded 只省 Python/kernels launch 与中间往返，不改变用户看到的 token 合同。

why / omitted / source / evidence

为什么 guards 看起来“过度严格”

CUDA

WHY HERE

graph 内 acceptance 只能读取捕获时绑定的 static buffers。凡是 graph 外才应用的 grammar、penalty、custom processor 或 simulation，都会让 graph 中的 logits/长度语义落后，所以必须禁用 folded trust。

FAIL

IF GUARDS OMITTED

最危险的不是性能下降，而是使用未经 grammar/logit 调整的 greedy 结果，或在本轮实际未 replay graph 时读取旧 buffer。两者都会造成错误 token/长度/KV 提交。

GUARD

FEATURE BOUNDARY

sampling/mixed 不会得到 proposal.folded=True；本页不展开其拒绝采样数学。Target compact rows 与 scatter 物理布局也不重复，分别链接到 06 与 05。
