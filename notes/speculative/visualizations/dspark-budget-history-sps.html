为什么 / 边界

启动、缺 profile 与 0/None 必须分开理解

overlap warm-up

relay 尚未积累两轮或 copy event 未 ready 时，resolve 可能为 None；这轮 budget 也是 None。

non-overlap warm-up

carry 初始 generation 不匹配，历史 survival 回退全 1，再结合 SPS table 计算，不等同于直接返回 None。

无 profiled SPS

flat SPS + 非负 survival 使最优通常退化到 verify-all；COMPACT 识别为 _is_verify_all 并复用 uniform layout。

budget 0 vs None

0 是“明确不选 extra”；None 是“本轮无 budget 控制”。mandatory anchor floor 不在 budget optimizer 中扣除。
